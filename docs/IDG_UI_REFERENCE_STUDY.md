# 좀비와 드래곤 · 창(팝업) 디자인 참고 조사

작성: 2026-11-14 · 게임 부장 보조 조사 · 대상: 초등학생이 많이 하는 가로 화면 게임 30개

## 0. 먼저 읽어 주세요 (조사 방법과 한계)

- 글로 된 자료(공식 도움말, 공식 공지, 위키, 가이드 기사, 스토어 소개)를 읽어서 정리했습니다.
- **스크린샷 그림 자체는 보지 못했습니다.** 그림 파일을 내려받지 말라는 지시가 있었고, 그림 사이트(Interface In Game, Game UI Database)는 글 설명이 거의 없습니다. 그래서 «창이 화면의 몇 %다», «버튼 색이 무슨 색이다» 같은 숫자와 색은 대부분 **확인 못함**입니다.
- 표시 약속
  - **[확인]** = 위 글 자료에서 직접 읽은 내용 (주소 있음)
  - **[기억]** = 제가 아는 일반 지식. 이번에 글로 확인하지 못함. 참고만 하시고, 꼭 필요하면 직접 게임 화면으로 대조해야 합니다.
  - **[확인 못함]** = 자료가 없음
- 위키(Fandom, 나무위키 등)는 접속이 막혀서 못 읽은 곳이 많습니다. 쿠키런 킹덤, 카트라이더 러쉬플러스는 한국어 검색에서도 화면 배치 자료를 못 찾았습니다.
- 세로 화면 게임은 뺐습니다: 클래시 로얄, 서브웨이 서퍼, 러시 로얄, 아처리, 크로시 로드, 포켓몬 카페 리믹스, 토킹톰 시리즈, 머지 드래곤즈, 팀파이트 택틱스 모바일(기본 세로).

## 2. 화면별 공통 규칙

### 2-1. 로비(메인 화면)

가장 흔한 배치 2가지.

**A. 가운데는 내 캐릭터, 양옆은 세로로 줄 선 메뉴 단추, 아래 가운데~오른쪽은 큰 «플레이» 단추**
- 브롤스타즈 [확인, 2019년 가이드]: 왼쪽에 세로로 브롤러·상점·소셜, 오른쪽에 전투 기록·순위·소식·방 만들기. 위 오른쪽에 재화 막대 + 채팅 + 설정. 위 왼쪽에 트로피 길·내 정보. 아래 가운데에 이벤트, 큰 플레이 단추.
- 아레나 오브 발러 [확인]: 왼쪽 세로 줄(아바타 아래)에 상점·영웅·아르카나·무기고·가방·길드. 가운데에 일반전/랭크전.
- 스텀블 가이즈 [확인]: 상점·꾸미기·친구·클럽·미션·파티·플레이로 바로 가기. 능력 칸은 캐릭터 바로 옆(4칸을 메인 메뉴에 노출).
- 포켓몬 유나이트 [확인]: 이벤트 단추(받을 보상이 있으면 빨간 점), 친구 목록은 화면 왼쪽(접속 중이면 초록 점).

**B. 아래 양쪽 모서리에 두 개의 큰 단추 (게임의 두 축을 같은 무게로)**
- 클래시 오브 클랜 [확인]: 왼쪽 아래 «전투», 오른쪽 아래 «건설» 서로 거울처럼 배치. 설정과 받은편지함은 왼쪽 위 «프로필» 안으로 넣음. 이벤트 묶음은 접을 수 있는 트레이.

참고: 쿠키런 킹덤은 «플레이»를 누르면 지도처럼 8개 구역(왕국·월드·광장·아레나·길드·챌린지·업그레이드·추천)이 열리는 방식으로 개편 [확인]. 모드 버튼에 대표 보상 아이콘이 보임 [확인].

공통점
- 메뉴 단추가 많아지면 **«큰 묶음 단추 하나 안에 모으기»**로 정리하는 흐름이 뚜렷함 (클래시 오브 클랜 개편, 포켓몬 유나이트 상점 통합, 쿠키런 메인 메뉴 개편). 모두 «화면이 복잡하다»는 불만 뒤에 나온 개편 [확인].
- 가로 화면에서는 **왼쪽·오른쪽 가장자리는 단추 줄, 가운데는 캐릭터/그림**으로 비워 둠.

### 2-2. 아이템 상점

가장 흔한 배치 3가지.

1. **위(또는 아래)에 가로 탭, 안에는 카드**
   - 브롤스타즈 [확인]: 가로로 넘기는 한 줄 상점, 아래 탭 4개(추천 · 무료 매일 선물 · 꾸미기 · 재료). 첫 칸은 브롤패스, 시간 한정 묶음은 최대 6개, 내일 선물은 미리 보이되 잠김. 한정 상품엔 타이머·희귀도 표시.
   - 스텀블 가이즈 [확인]: 5개 구역(패스 · 룰렛 · 특가 · 무료 보상 · 젬). 상품에 «추천·인기·신규·최고 특가·무료·할인» 이름표.
2. **왼쪽 세로 탭, 오른쪽 상품 칸**
   - 아레나 오브 발러 [확인]: 탭 순서가 추천 · 영웅 · 스킨 · 아이템 · 아르카나 · 뽑기. 영웅 탭은 위에 정렬 드롭다운과 분류 단추. (탭이 왼쪽인지 위인지는 글로 확인 못함.)
   - 브롤할라 [확인]: 왼쪽에 검색창, 탭마다 필터(영웅·콜라보·스킨·색상 탭에만 필터).
3. **목록(행) 방식**
   - 식물 vs 좀비 2 [확인]: 탭 7개(추천 · 피냐타 · 식물 · 코인 · 젬 · 묶음 · 업그레이드). 코인·젬 탭은 행 한 줄마다 「수량 · 짧은 설명 · 그림 · 가격」. 묶음 탭은 표 방식. 위 오른쪽 재화 옆 «+» 단추를 누르면 빠른 충전 창이 열림.

공통점
- 재화 막대는 **오른쪽 위**: 브롤스타즈 · 스텀블 가이즈 · 아레나 오브 발러 · 헝그리 샤크 · PvZ2 모두 [확인]. 재화를 누르거나 «+»를 누르면 충전 창으로 직행.
- 상품마다 **어느 재화로 사는지** 가격 옆 아이콘으로 보임 [확인, 포켓몬 유나이트].
- 가장 비싼/인기 상품을 **더 크게** (로블록스 공식 글 [확인]), 돈이 모자라면 **가격 글씨를 빨갛게**, 아직 못 여는 상품은 **자물쇠** [확인, 로블록스 공식 글].
- 신규 상품 «NEW» 이름표 [확인, 포켓몬 유나이트].
- 헝그리 샤크는 «가격 단추를 누르면 설명과 확인 창이 한 번 더 뜸» [확인].

### 2-3. 꾸미기(스킨 · 모자)

- **왼쪽 세로 메뉴로 분류 바꾸기 + 가운데에 내 캐릭터 미리보기 + 오른쪽에 고르기 칸**
  - 스텀블 가이즈 [확인]: 왼쪽 메뉴로 스킨·이모트·능력·승리 동작·발자국. 스킨은 희귀도·보유 여부로 거르기. 입기 전에 미리보기.
  - 마인크래프트 [확인]: 드레싱룸 왼쪽 사이드바. 캐릭터 만들기는 «몸 / 스타일» 두 갈래.
- **가로 탭 여러 개(작은 아이콘 탭)**
  - 어몽 어스 [확인]: 탭 7개(색 · 모자 · 스킨 · 바이저 · 펫 · 이름표 · 코스미큐브). 탭 안의 달러 표시를 누르면 마켓으로 연결.

## 5. 창 크기 · 여백 · 제목 표시 방식

- **창이 화면의 몇 %인지**: 글 자료로는 **확인 못함** (숫자를 적은 자료가 없음).
- [확인] 클래시 오브 클랜 건설 메뉴: **뒤에 마을(게임 화면)이 계속 보임**. 즉 창이 화면을 다 덮지 않음.
- [확인] 브롤스타즈 상점: 가로로 넘기는 **전체 화면 방식**. 클래시 오브 클랜 건설 메뉴는 **일부만 덮는 방식**. 두 방식이 섞여 있음.
- [확인] 포켓몬 유나이트: 여러 상점을 **한 화면으로 합침**(배경 모양만 예전 상점 느낌 유지).
- [확인] 로블록스: 닫기 X는 **오른쪽 위**. 제목 위치는 글에 없음.
- 제목을 리본으로 하는지 글씨만 하는지: **확인 못함** (그림을 못 봄). [기억]으로는 브롤스타즈·클래시 계열은 **왼쪽 위에 글씨 제목 + 오른쪽 위 X**이고, 쿠키런 킹덤은 장식 있는 제목판을 씀. 직접 캡처로 대조 필요.
- [추정] 가로 화면 창은 **가로 70~90%, 세로 80~95%**쯤이 가장 많을 것으로 보지만, 이것은 확인된 숫자가 아니라 제 추정입니다.

## 6. 우리 게임에 바로 쓸 추천 10가지

5. **도감은 가진 것만 색깔, 없는 것은 어두운 실루엣 + 자물쇠, 돈으로 여는 것은 자물쇠 색을 따로.** (PvZ2 알마낙 [확인])
