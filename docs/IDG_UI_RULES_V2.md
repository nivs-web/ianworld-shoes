# 좀비와 드래곤 — 창 디자인 규칙 2판 (가로 전용) · 11/14 겜부장

대표님 결정(11/14): **모든 기기 가로만**. 로비는 마음에 듦 — 문제는 «뜨는 창들에 규칙이 없다». 그래서 아래 한 장으로 모든 창을 맞춘다.
시안 바탕 파일 = `tools/_uimock/kit.css` (모든 A·B·C 시안이 이 한 장만 씀). 확정되면 게임 CSS 로 옮긴다.

## 1. 창 틀
- 폭 = 화면 가로의 **80% 이하** (설정 · 선물함처럼 내용이 적은 창 = 72%). 높이 = 92% 이하.
- 짙은 보라 판 · 바깥 검보라 3px · 안쪽 금 1px · 모서리 둥글게. **빨간 리본 없음 · 위아래 금띠 없음.**
- 머리 줄 하나 : 왼쪽 위 = 제목(큰 글씨 · 3px 검은 테) · 오른쪽 위 = (바로가기 주황 단추) + 재화 알약 + 빨간 X.
- X = 늘 오른쪽 위 · 위 여백 = 오른쪽 여백.

## 2. 창 안 배치 (가로를 쓰는 법)
- 분류가 있는 창(아이템샵 · 도감 · 연구소) = **왼쪽 30% 메뉴 단추 줄 + 오른쪽 물건만** (대표님 제안 · 브롤스타즈 · 클래시 계열 공통).
- 분류가 없는 창(선물함 · 설정 · 결과) = 한 줄 목록 + 아래 종이 안내 + 큰 단추 하나.
- 고르는 창(스테이지) = 왼쪽 «무엇을 고를지»(월드 · 난이도) · 오른쪽 «고를 칸»(스테이지).

## 3. 단추 뜻 (이것 말고는 쓰지 않음)
| 단추 | 뜻 |
|---|---|
| 큰 빨강 (btn_red2) | 싸우러 들어가기 — 모험시작 · 출격! · 다시하기 · 전투개시! · 다음 판 (한 화면에 하나) |
| 큰 초록 (btn_green3) | 강해지러 가기 — 파워업 (한 화면에 하나) |
| 작은 초록 | 사기 · 레벨업 · 받기 · 모두 받기 (값 = 코인/젬 그림 + 숫자 · 모자라면 숫자만 빨강) |
| 보라 | 고르기 · 탭 · 정렬 · 돌아가기 (골라진 것 = 노란 테) |
| 주황 | 다른 창 바로가기 (아이템샵 ↔ 꾸미기 · 로비로 · 파워업 → 아이템샵) · 끝에 › |
| 회색 | 잠김 · 못 함 — 누르면 «왜 잠겼는지» 한 줄 |
| 빨간 네모 X | 닫기 하나만 |

## 4. 글씨
- 갈무리11 굵게 하나. 제목 = 3px 검은 테 · 본문 · 단추 = 2px · 작은 보조 글씨 = 1px.
- 이름(카드 제목) = 거의 흰색 · 보조 글씨 = 한 단계 어두운 연보라.
- **종이 위 글씨**는 어느 창이든 같은 크기(12px) · 같은 짙은 갈색 · 같은 여백.

## 5. 알림 배지 (새로 · 브롤스타즈식)
- 받을 것이 있으면 **빨간 동그라미 + 숫자**, 셀 수 없는 새 소식은 **빨간 점**. 받으면 바로 사라짐.
- 붙는 곳 : 로비 [선물] · [도전과제] · [더보기](안에 새것) · 아이템샵 왼쪽 메뉴 [특가] · [선물함].

## 6. 선물함 기획 (새로)
- **지금** : 선물은 «레벨 선물»(10레벨마다) 하나뿐이고, 로비에 들어오면 상자 연출이 자동으로 뜬다. 도전과제 보상은 도전과제 창에서 따로 받는다. 선물함은 없다.
- **제안** : 로비 위 줄(코인 판 왼쪽)에 [선물] 단추 + 숫자 배지 → 선물함 창. 아이템샵 왼쪽 메뉴에도 [선물함] (대표님 질문 «아이템샵에 선물함 뜨면 안 되나» → 됨, 두 곳 다 같은 창).
- 선물함에 들어오는 것 : ① 레벨 선물(자동 연출 대신 선물함에 쌓임 · 첫 번째만 연출) ② 명예의 전당 시즌 상 ③ 운영진 선물(점검 보상 · 기념) — 도전과제는 지금처럼 도전과제 창에서 받기(숫자 배지는 도전과제 단추에).
- 한 줄 = 그림 · 이름 · 어디서 온 선물(색 알약) · 남은 날 · [받기]. 아래 [모두 받기]. 30일 보관.
- 운영진 선물은 서버(파이어베이스)에 «선물 목록»이 필요 → 만들기 전에 따로 여쭙는다(돈 0원 · 규칙 파일 수정 필요).

## 7. 크기 아끼기
- 새 그림을 거의 안 씀 : 틀 · 단추 · 배지 = CSS, 그림은 이미 있는 아이콘 · 드래곤 머리 · 월드 배경만.
