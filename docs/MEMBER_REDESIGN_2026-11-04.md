### ⚠ 요금제 확인 필요 — 무료(Spark)는 **동시 연결 100개가 상한**

지금은 로그인한 **모든 사람**이 접속 표시 때문에 RTDB에 연결한다. 무료 요금제면 101번째 사람부터
멀티·쪽지·대결 신청이 **아예 안 된다**(요금 폭탄이 아니라 기능 정지). 100명을 넘길 계획이면 Blaze 전환이 필요하고,
그 전이라도 아래 3-⑧(연결은 필요할 때만)을 하면 "동시 연결 = 멀티·친구 화면을 쓰는 사람"으로 줄어든다.

## 3. 다시 만든 설계 (화면 · 데이터 · 비용)

| # | 기능 | 화면 | 데이터 (RTDB) | 비용 | 결정 |
|---|---|---|---|---|---|
| ① | **운영자 통계** | 운영자 계정일 때만 설정 메뉴에 «통계»: 오늘 접속자 수 · 지금 동시접속 · 오늘 최대 동시접속 · 최근 7일 접속자 | `stats/days/{날짜}/u/{uid}: true`(본인이 하루 1번) · `stats/days/{날짜}/n` 카운터 · `stats/live` 동시접속(+1, 끊기면 −1) · `stats/days/{날짜}/peak` | 사람당 하루 ~100B 쓰기, 읽기는 운영자가 열 때만 | 새로 만든다 |
| ② | 접속자 목록(전원) | 메뉴에서 삭제 | `presence` 구독 없음 | −219 MB/h | **뺀다** (대표님 지시) |
| ③ | 접속 표시 | 안 보임 (친구 접속·방 유령 판정·대결 가능 여부의 근거) | `presence/{uid}` 그대로, 15초 신호(쓰기는 무료·이제 퍼지는 곳이 없음) | ~0 | 유지 |
| ④ | **친구 추가** | 대기방·결과 화면에서 이름 → 유저카드 → «친구 추가» | `friends/{내uid}/{친구uid}: {n: 이름, at}` 본인만 읽기/쓰기 | 1회 ~60B | 새로 만든다 |
| ⑤ | **접속한 친구만 보기** | 메뉴 «친구» — 접속 중인 친구 먼저, 상태(로비/게임중·어느 게임) | 열 때 친구 수만큼 `presence/{친구}` 잎 읽기, 화면이 떠 있는 동안 30초마다 | 친구 20명 × 40B = 0.8KB/회 | 새로 만든다 (실시간 구독 안 함) |
| ⑥ | **친구와 같이 하기** | 친구 줄 → «같이 하기»(게임 고르기) → 비밀방 + 초대 | 기존 비밀방 + 기존 대결 신청 쪽지 재사용 | 쪽지 1통 | 기존 것 조립 |
| ⑦ | 쪽지 · 대결 신청 | 받는 쪽 팝업 그대로, 보내는 곳은 친구 목록·유저카드 | `inbox/{uid}` 그대로, 구독은 최근 30통만 | −26 MB/h | 유지 + 다이어트 |
| ⑧ | 랜덤 매칭 · 비밀방 | 그대로 | 방 스캔 12개 | 그대로 | 유지 |
| ⑨ | (선택) 연결은 필요할 때만 | 싱글만 하는 사람은 RTDB 연결 안 함, 로비에서 1분마다 쪽지 확인 | `goOffline/goOnline` | 동시 연결 수 대폭 감소 | 대표님 결정 필요 (초대 팝업이 최대 1분 늦음) |

### 친구는 "한쪽 추가"(즐겨찾기형)를 추천

- 상대 수락 절차가 없어 화면·규칙이 단순하다. 상대에게는 «OO님이 친구로 추가했어요» 쪽지(끌 수 있음).
- 쪽지·대결 신청은 지금처럼 상대의 **수신 거부·차단**(`prefs`)이 서버 규칙에서 막는다 — 친구 추가로 뚫리지 않는다.
- 서로 수락(맞친구)이 꼭 필요하면 쪽지 종류 `friendReq` 하나만 더하면 된다 (비용 차이 없음).

## 4. 운영자 판별 — 이름이 아니라 uid

- 화면 이름(«아빠게임왕»)은 누구나 바꿀 수 있으므로 쓰지 않는다. **대표님 구글 계정의 uid** 로 판별한다.
- 화면(메뉴 보이기)은 앱 설정값으로, **통계 읽기 권한은 서버 규칙**으로 막는다 → 규칙에 그 uid가 들어가야 하므로
  **대표님의 규칙 게시가 필요**하다(이번에 `presence .indexOn` 과 함께 한 번에).
- 필요한 것: 대표님 uid (Firebase 콘솔 → Authentication → 사용자 → «사용자 UID», 또는 로그인된 브라우저에서 확인).

## 5. 만드는 순서 (각 단계 커밋, 푸시 금지)

1. 설계안 + 비용표 (이 문서)
2. 운영자 통계 + 접속자 목록 제거 (+ 규칙 초안: `stats`, 운영자 uid 자리)
3. 친구 추가 · 접속한 친구 · 같이 하기 · 쪽지함 30통 (+ 규칙 초안: `friends`)
