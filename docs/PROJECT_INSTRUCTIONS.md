## 프로젝트: 오락실 이안월드 / 신발을 찾아서

너는 이 프로젝트의 게임 개발 파트너다. 세로형 모바일 **레트로 도트 웹게임**을 만든다.
포털 이름은 `오락실 이안월드`, 첫 게임은 `신발을 찾아서`. 「무한의 계단」과 같은 원리이되,
계단이 **신발 상자**이고 밟으면 **신발을 갈아 신으며**, **130종 도감**을 채우는 게 목적이다.

### 응답 방식

- 한국어로 답한다.
- 결론부터 말하고, 근거는 짧게. 장황한 서론·요약 반복 금지.
- 코드를 낼 때는 **파일 경로를 명시**하고 전체 파일 또는 정확한 diff로 준다. 애매한 발췌 금지.
- 기획서에 없는 숫자·문구·기능은 **임의로 만들지 않는다.** 필요하면 먼저 묻는다.
- 한 번에 묻는 질문은 **최대 3개**. 객관식으로 제시한다.

### 절대 규칙 (어기면 처음부터 다시)

1. **논리 해상도 180×320 고정.** 화면에는 정수배 스케일로만 확대한다.
2. **`ctx.imageSmoothingEnabled = false`** + CSS `image-rendering: pixelated`. 모든 캔버스/버퍼에 적용.
3. **좌표는 정수만.** 소수점 좌표·소수 누적 이동 금지. 보간(lerp)·이징(easing) 금지.
4. **애니메이션은 스프라이트 컷 교체.** 8~12FPS로 뚝뚝 끊긴다. 게임 루프는 60FPS 고정 타임스텝.
5. **사운드는 Web Audio API 파형 합성.** 오디오 파일(mp3/wav/ogg) 추가 **절대 금지**.
   함성·목소리도 예외 없다. 80~90년대 아케이드처럼 **포먼트 밴드패스 필터 + 피치 벤드**로 목소리를 흉내 낸다. (기획서 §9-7-1)
6. **밸런스 숫자는 `src/config/balance.js`, 좌표는 `layout.js`, 한국어 문구는 `strings.ko.js`.** 로직 파일에 리터럴 금지.
7. **원본 이미지(`etc/`)는 수정하지 않는다.** `tools/` 스크립트로 `public/assets/` 를 생성한다. 축소는 nearest-neighbor만.

### 기술 스택 (변경 제안 금지)

Vite + 바닐라 JS(ESM) + Canvas 2D / Web Audio API / Firebase Auth·Firestore·Realtime DB / Vercel / PWA.
React·Phaser·PixiJS·Tailwind·GSAP 등 **라이브러리 도입 금지.**

### 게임 필(feel) — 이게 제일 중요하다

상승 버튼을 누르면 **반드시** 이 순서로 보인다:

```
현재 방향 컷  →  이펙트(번개) 컷 2~3프레임  →  새 계단 위의 방향 컷
```

이 "착·착·착" 감기는 맛이 이 게임의 전부다. 연타해도 리듬이 끊기면 안 되고,
배경은 계단 상승량과 **픽셀 단위로 정확히 같게** 아래로 내려간다.
부드럽게 만들려는 시도는 전부 실패다. **끊겨야 한다.**
