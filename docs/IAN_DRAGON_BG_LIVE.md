# 좀비와 드래곤 — 배경 «살아 있게» 기획 (그림 담당)

> 작성 : 겜부장 보조(그림 담당) · 2026-11-11 · 대표님 질문 «배경은 10개인가? 배경 그림 자체는 안 움직이나? 가만히가 나을까, 살아 있는 게 나을까?»

## 1. 지금 배경은 이렇다

| 항목 | 지금 |
|---|---|
| 개수 | **월드마다 1장 = 10장** (월드 1개 = 스테이지 10판, 100판이 같은 배경을 10판씩 함께 씀) |
| 그림 | `ai/bg/w01~w10_panel.png` 한 장짜리 통그림 (하늘 · 먼 성 · 소품 · 땅이 한 장에 붙어 있음) |
| 그림 자체 움직임 | **없음.** 카메라를 옮기면 배경 전체가 한 덩어리로 같이 밀린다 (멀고 가까움의 차이 없음) |
| 그 위에서 움직이는 것 | ① 재미 요소 17종 — 1~1.5초마다 하나 (자전거 · 마녀 · 박쥐 · 달 얼굴 · 두더지 …) ② 분위기 입자 — 월드 1 반딧불 · 2 불티 · 3 구름 조각 · 4 눈 · 5 불꽃+연기 |
| 문제 1 | 월드 6~10 은 분위기 입자가 따로 없어 **전부 월드 1 반딧불**이 나온다 (사막에도 반딧불) |
| 문제 2 | 배경 폭 1,273칸 < 전장 폭 1,240~1,710칸 → 긴 판에서는 오른쪽에 **배경이 좌우 거울로 한 번 더** 붙는다 (먼 성 · 소품이 쌍둥이로 보임) |

## 2. 가만히 vs 살아 있게 — 판단

| | 가만히 (지금) | 살아 있게 |
|---|---|---|
| 좋은 점 | 유닛 · 체력 · 브레스가 잘 보인다 · 가볍다 | «그림 속 세상» 느낌 · 대표님 참고 그림의 맛(빛 · 연기 · 흐름) · 오래 봐도 덜 지루 |
| 나쁜 점 | 사진 위에서 싸우는 느낌 · 10판 내내 같은 화면 | 너무 움직이면 아이들 눈이 유닛에서 떨어진다 · 폰이 뜨거워질 수 있음 |

**추천 : «조용히 살아 있게».** 땅(유닛이 싸우는 띠)은 지금처럼 가만히, **하늘 · 먼 곳만 느리고 은은하게** 움직인다. 재미 요소(가끔 나오는 깜짝 볼거리)와 겹치지 않게 «늘 흐르는 것»만 맡는다.
규칙 : ① 움직임은 화면 위쪽 2/3 (땅 줄 위) ② 느리게 (한 바퀴 4초 이상) ③ 밝기 변화는 작게 (깜빡이 아님, 숨쉬기) ④ 입자 상한 40 그대로 ⑤ 운영자 스위치로 끌 수 있게.

## 3. 방법 3단계 (싼 것부터)

### A단계 — 그림은 그대로, 코드로 숨 불어넣기 (돈 0 · 추천 먼저)
배경 그림 위 «빛 자리표»(재미 요소 자리표 funSpots 처럼 사람이 잼)에 빛무리 · 연기 · 안개를 얹는다.

| 월드 | 늘 흐르는 것 (A단계) | 지금 입자 |
|---|---|---|
| 1 달밤 초록 언덕 | 달 빛무리 숨쉬기 · 횃불/초록 불 깜빡 · 낮은 안개 띠 흐름 | 반딧불 |
| 2 부글부글 화산 | 용암 빛 출렁(밝기 맥박) · 화산 연기 기둥 | 불티 |
| 3 뭉게구름 하늘섬 | 구름 띠 천천히 흐름 · 폭포 반짝 | 구름 조각 |
| 4 꽁꽁 얼음골 | 오로라 색 일렁 · 얼음 반짝 | 눈 |
| 5 덜컹덜컹 쇠 광산 | 경고등 깜빡 · 굴뚝 연기 | 불꽃 + 연기 |
| 6 으스스 유령 묘지 | 땅 안개 흐름 · 무덤 초록빛 | **새로** 도깨비불 (지금 반딧불) |
| 7 모래바람 사막 | 가로 모래바람 띠 · 아지랑이 | **새로** 모래 알갱이 |
| 8 끈적끈적 독 늪 | 늪 기포 퐁퐁 · 초록 안개 | **새로** 기포 |
| 9 반짝반짝 수정 동굴 | 수정 반짝(별처럼) · 빛줄기 | **새로** 반짝 가루 |
| 10 좀비 드래곤 성 | 먼 번개 번쩍(드물게) · 성 창문 붉은 빛 | **새로** 재 흩날림 |

- 그림 담당 : 월드마다 빛 자리표(횃불 · 창문 · 용암 · 수정 좌표) 재기 + 확인 그림 — 약 2시간
- 겜부장 : 빛무리 · 연기 · 안개 코드 + 월드 6~10 입자 5종 — 약 2~3시간
- 비용 : **$0** (빛무리는 동그라미 그림 1장을 색 · 크기만 바꿔 씀)

### B단계 — 멀고 가까움(겹) 나누기 (월드당 약 $0.2 · 10월드 약 $2~3)
배경을 **하늘 겹(달 · 구름 · 먼 성)** 과 **땅 겹(소품 · 땅)** 2장으로 다시 그린다. 카메라가 움직이면 하늘은 천천히(0.3배), 땅은 그대로 → 화면에 깊이가 생긴다. 하늘 겹은 가로로 이어지게 그려서 **문제 2(거울 쌍둥이)도 같이 해결**.
- 제미나이 : 하늘 겹 1장(2K 21:9 · 이음새 없게) + 땅 겹 1장(하늘 자리 분홍 → 투명) / 월드, 다시 뽑기 포함 약 $0.2~0.3
- 그림 담당 : 생성 · 자르기 · funSpots 자리표 다시 재기 — 월드당 약 30분 (10월드 약 5시간)
- 겜부장 : 겹 2장 + 서로 다른 속도 — 약 1시간 (한 번 만들면 10월드 공통)
- **먼저 월드 1 하나만 시험 (약 $0.3)** → 갤러리에서 지금 배경과 나란히 움직여 보고 대표님이 정하신다.

### C단계 — 그림 속 물체 따로 움직이기 (나중 · 필요하면)
풍차 날개 · 깃발 펄럭 · 폭포 물줄기처럼 배경 소품을 «부품»으로 따로 그려 코드가 움직인다. 소품마다 $0.07 · 월드마다 2~3개. 효과는 크지만 A · B 로 충분한지 먼저 본다.

## 4. 순서 제안 · 정하실 것

1. **A단계 10월드 전부** (돈 0) — 바로 시작 가능. 사막 반딧불 같은 어색함도 같이 고친다.
2. **B단계 월드 1 시험** (약 $0.3) → 대표님이 보고 «좋다»면 나머지 9월드 (약 $2.5).
3. C단계는 A · B 를 보고 나서.

정하실 것 : ① 추천대로 «조용히 살아 있게»로 갈지 ② A단계 시작 ③ B단계 월드 1 시험($0.3) 여부.
