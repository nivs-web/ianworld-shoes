## 3. 디자인을 끌어올릴 «터치» — 연구

1. **화면마다 색을 하나로** : 게임 안(전투 · 로비)은 «남보라 돌 + 금테 + 주황 불빛» 하나로 맞춘다. 지금 로비 · 창은 오락실 공용 크림 · 갈색이라 배너 · 전투와 따로 논다 → 가장 큰 위화감.
2. **픽셀 크기 통일** : 새 아이콘은 제미나이 그림을 **게임과 같은 32칸 바탕 → 3배 최근접**으로 줄여 넣었다 (반투명 제거). 캐릭터와 같은 «칸 굵기»라 한 화면에서 섞여도 튀지 않는다. 로비 배경 · 버튼 판처럼 넓은 것만 매끈하게.
3. **눌러야 하는 것은 따뜻하게, 나머지는 차갑게** : 시작 · 브레스 · 소환처럼 누르는 것 = 주황/금, 정보 · 배경 = 보라/남색. 아이들이 «어디를 누르지?»를 색으로 바로 안다.
4. **달빛 테두리 한 줄** : 모든 그림의 왼쪽 위에 밝은 테두리 → 어두운 바탕에서도 모양이 또렷. 어두운 아이콘(그림자 · 닻)은 밝은 테두리 1칸을 더하면 띠 위에서 읽힌다 (다음 차례).
5. **판(9조각) 한 벌로 전부** : 테두리 판 1장을 9조각으로 늘려 쓰면 로비 판 · 창 · HUD 띠가 같은 재질이 된다 → 그림 몇 장으로 화면 전체가 통일.
6. **움직임은 코드로** : 브레스 준비 아이콘 깜빡 · 시작 버튼 숨쉬기 · 메뉴 아이콘 살짝 흔들 — 그림을 더 그리지 않고 CSS 로 (겜부장).
